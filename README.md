# Retail Sales & Customer Performance Analytics

## Project Overview

This project analyzes retail transaction data to identify sales performance trends, customer behavior, product performance, and profitability opportunities.

The objective is to transform raw retail data into actionable business insights using data analytics techniques.

---

## Business Questions

### Sales Performance
- How does sales performance change over time?
- Which region contributes the highest sales?
- Does high sales always generate high profit?

### Customer Analysis
- Who are the highest-value customers?
- Which customer segments contribute the most revenue?

### Product Analysis
- Which products and categories drive sales?
- Which products generate the highest profit?

### Discount & Profitability
- Does discount strategy impact profitability?
- How does discount affect profit margin?
